# 历史日前申报查询页面设计

## 背景

现有"日前用电侧申报V2"系统（`/daily-demand-report-v2`）支持用户完成 Step 1~3 的完整申报流程，但用户提交申报后无法查看历史申报记录。

本次设计新增"历史日前申报查询"页面，复用现有 6 个组件，展示用户历史申报的快照数据。

## 设计目标

1. 用户提交申报时，后端存储**完整的组件数据快照**，而非当前的碎片化字段
2. 历史查询页面直接使用存储的快照数据注入组件渲染
3. 右侧提供日期筛选面板，按年-月-日展示日历，允许用户快速切换查看

## 架构概览

```
提交流程（数据写入）：
  index.vue → store.submitDeclaration() → POST /api/daily-declaration/v2/submit
    → 存储完整 7 个 JSON 字段到 daily_declaration_v2 表

查询流程（数据读取）：
  DailyDemandReportV2History/index.vue
    → historyStore.fetchRecord(date) → GET /api/daily-declaration/v2/history?date=XXXX-XX-XX
    → 后端返回完整 record → historyStore 用 computed 派生组件数据
    → 通过 props 注入 6 个组件渲染

组件设计模式：
  所有组件改为 props（数据）+ emit（事件）驱动，彻底与 store 解耦。
  原首页 index.vue 通过 props 传 store 数据 + emit 调 store action。
  历史页面通过 props 传 historyStore 数据，readonly 模式不需要 emit。
```

## 后端改动

### Model — DailyDeclarationV2.js

`create()` 和 `update()` 方法改为存储 7 个字段（`dateInfo`, `aiQueryText`, `queryResults`, `allSelectedDates`, `priceComparisonData`, `strategyPeriods`, `adjustedRatios`），JSON 字段通过 `JSON.stringify()` 序列化后写入。

`parseRow()` 函数对应解析全部新 JSON 字段。

`findByUserAndDate()` 和 `findHistoryDates()` 无需改动。

### Route — POST /api/daily-declaration/v2/submit

接收 `req.body` 字段改为：

```javascript
const {
  declaration_date,
  dateInfo,
  aiQueryText,
  queryResults,
  allSelectedDates,
  priceComparisonData,
  strategyPeriods,
  adjustedRatios,
} = req.body;
```

### Route — GET /api/daily-declaration/v2/history?date=XXXX-XX-XX

无需改动。已返回 `DailyDeclarationV2.findByUserAndDate()` 的完整 `record`，`parseRow()` 已解析所有 JSON 字段，前端直接使用。

## 前端改动

### 原则：所有组件改为 Props + Emit

```
改造前：组件内部 const store = useDailyDeclarationV2Store() 直接读写
改造后：组件通过 props 接收数据，通过 emit 发出操作事件

原页面（index.vue）：
  store → props ↓ → 组件 → emit ↑ → store action

历史页面（History/index.vue）：
  historyStore → props ↓ → 组件（readonly，不 emit）
```

### 1. 各组件 Props 和 Emit 定义

#### QueryResultTable.vue

| 当前 | 改为 |
|------|------|
| `const store = useDailyDeclarationV2Store()` | 删除 |
| `store.queryResults` | `props.results` |
| `store.selectedDates` | `props.selectedDateSet` |
| `store.selectQueryResult(row)` | `emit('select', row)` |
| `store.deselectQueryResult(date)` | `emit('deselect', date)` |

**Props：**
- `results`: Array（默认 `[]`）
- `selectedDateSet`: Array/Set（默认 `[]`）
- `readonly`: Boolean（默认 `false`）

**Emits：**
- `select`：用户选中某行
- `deselect`：用户取消选中某行

**`enhancedResults` computed 改造：** 内联到模板或改为接收 props。

#### SelectedDatesTable.vue

| 当前 | 改为 |
|------|------|
| `const store = useDailyDeclarationV2Store()` | 删除 |
| `store.allSelectedDates` | `props.dates` |
| `store.removeSelectedDate(date)` | `emit('remove', date)` |

**Props：**
- `dates`: Array（默认 `[]`）
- `readonly`: Boolean（默认 `false`）

**Emits：**
- `remove`：用户移除某日期

#### PriceComparisonTable.vue

| 当前 | 改为 |
|------|------|
| `const store = useDailyDeclarationV2Store()` | 删除 |
| `store.priceComparisonData` | `props.data` |

**Props：**
- `data`: Object/Array（默认 `null`）

**Emits：** 无（纯展示组件）

#### StrategyTableV2.vue

| 当前 | 改为 |
|------|------|
| `const store = useDailyDeclarationV2Store()` | 删除 |
| `store.strategyPeriods` | `props.periods` |
| `store.strategySummary` | `props.summary` |
| `store.declarationDate` | `props.declarationDate` |
| `store.getAdjustedRatio(p)` | `props.adjustedRatios[parseInt(p.period) - 1]` |
| `store.setAdjustedRatio(p, v)` | `emit('confirm-edit', { period, value })` |
| `store.resetAdjustedRatios()` | 组件内 resetAllRatios() 调用改为 emit |
| `store.setAdjustedRatio(p, default)` | `emit('reset-all')` |

**Props：**
- `periods`: Array（默认 `[]`）
- `summary`: Object（默认 `null`）
- `declarationDate`: String（默认 `''`）
- `adjustedRatios`: Array（默认 `[]`）
- `readonly`: Boolean（默认 `false`）
- `submitted`: Boolean（默认 `false`）

**Emits：**
- `confirm-edit`：用户确认调整比例
- `reset-all`：用户恢复默认比例

### 2. Store — dailyDeclarationV2.js（修改）

`submitDeclaration()` 改为无参，自动从当前 store 状态组装完整 payload：

```javascript
async function submitDeclaration() {
  const payload = {
    declaration_date: declarationDate.value,
    dateInfo: dateInfo.value,
    aiQueryText: aiQueryText.value,
    queryResults: queryResults.value,
    allSelectedDates: allSelectedDates.value,
    priceComparisonData: priceComparisonData.value,
    strategyPeriods: strategyPeriods.value,
    adjustedRatios: adjustedRatios.value,
  }
  const res = await submitApi(payload)
  return res.data
}
```

### 3. Store — dailyDeclarationHistory.js（新建）

独立 Pinia store，从 `GET /history` 返回的 `record` 派生数据：

```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { historyDatesApi, historyDetailApi } from '@/DailyDemandReportV2/api'

export const useDailyDeclarationHistoryStore = defineStore('dailyDeclarationHistory', () => {
  const historyDates = ref([])
  const currentDate = ref('')
  const record = ref(null)

  const dateInfo = computed(() => record.value?.dateInfo ?? null)
  const aiQueryText = computed(() => record.value?.aiQueryText ?? '')
  const queryResults = computed(() => record.value?.queryResults ?? [])
  const allSelectedDates = computed(() => record.value?.allSelectedDates ?? [])
  const priceComparisonData = computed(() => record.value?.priceComparisonData ?? null)
  const strategyPeriods = computed(() => record.value?.strategyPeriods ?? [])
  const adjustedRatios = computed(() => record.value?.adjustedRatios ?? [])

  async function fetchHistoryDates() {
    const res = await historyDatesApi()
    if (res.data.success) {
      historyDates.value = res.data.data
    }
  }

  async function fetchRecord(date) {
    const res = await historyDetailApi(date)
    if (res.data.success) {
      record.value = res.data.data
      currentDate.value = date
    }
    return res.data
  }

  return {
    historyDates, currentDate, record,
    dateInfo, aiQueryText, queryResults,
    allSelectedDates, priceComparisonData,
    strategyPeriods, adjustedRatios,
    fetchHistoryDates, fetchRecord,
  }
})
```

### 4. index.vue（修改）

新增 props 绑定和 emit 事件处理：

```html
<!-- Step2: AI查询面板 -->
<QueryResultTable
  :results="store.queryResults"
  :selected-date-set="store.selectedDates"
  @select="(row) => store.selectQueryResult(row)"
  @deselect="(date) => store.deselectQueryResult(date)"
/>

<!-- Step2: 已选中日期 -->
<SelectedDatesTable
  :dates="store.allSelectedDates"
  @remove="(date) => store.removeSelectedDate(date)"
/>

<!-- Step3: 价差表 -->
<PriceComparisonTable
  :data="store.priceComparisonData"
/>

<!-- Step3: 策略表 -->
<StrategyTableV2
  :periods="store.strategyPeriods"
  :summary="store.strategySummary"
  :adjusted-ratios="store.adjustedRatios"
  :declaration-date="store.declarationDate"
  :readonly="false"
  :submitted="store.submitted"
  @confirm-edit="({period, value}) => store.setAdjustedRatio(period, value)"
  @reset-all="store.resetAdjustedRatios()"
/>
```

`handleConfirmSubmit` 中的 payload 改为传完整数据。

#### 右侧日历面板设计

- `position: fixed; right: 0; top: 0; z-index: 1000`
- 展开宽度约 240px，可向右收起为窄条按钮（▶/◀）
- 顶部标题 "📅 历史申报查询" + 关闭按钮
- **年份区域**：2026年至当前年份，默认当前年展开
- **月份区域**：手风琴模式，同时只能展开一个月，默认当前月展开
- **日期区域**：从 1 日到该月最后一天

  - 无申报记录的日期显示为灰色，不可点击
  - 当前选中日期高亮（蓝色底色）
- 数据来源：`GET /api/daily-declaration/v2/history/dates` 返回的日期集合
- 点击日期 → `hs.fetchRecord(date)` → 所有组件通过 props 自动渲染
