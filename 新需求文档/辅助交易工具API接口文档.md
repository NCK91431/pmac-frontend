# 月度用电需求申报工作流 - API接口文档

## 一、接口概述

| 项目 | 说明 |
|------|------|
| **接口名称** | 月度用电需求申报工作流 |
| **功能描述** | 通过调用EMS系统接口获取历史负荷数据，分析预测下月用电量，生成月度需求申报表Excel文件 |
| **请求方式** | POST / GET（根据平台支持） |
| **返回格式** | JSON |
| **版本** | v1.0 |

---

## 二、请求参数

### 2.1 参数总览

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `target_month` | String | 否 | 当前月份+1 | 目标月份，格式：YYYY-MM |
| `company_names` | Array[String] | 否 | 所有公司 | 公司名称列表 |
| `historical_date_range` | String / Object | 否 | 当前日期-35至-4天 | 历史数据日期范围 |
| `date_type_override` | Array[Object] / String | 否 | 无 | 日期类型覆盖规则 |

### 2.2 参数详细说明

#### 2.2.1 `target_month` - 目标月份

| 属性 | 说明 |
|------|------|
| **类型** | String |
| **必填** | 否 |
| **默认值** | 自动计算为当前月份的下一个月 |
| **格式** | YYYY-MM |

**示例**：
```json
{
  "target_month": "2026-04"
}
```

**不填写时**：
- 当前是 2026年3月 → 默认值为 `2026-04`
- 当前是 2026年12月 → 默认值为 `2027-01`

#### 2.2.3 `historical_date_range` - 历史数据日期范围

| 属性 | 说明 |
|------|------|
| **类型** | String 或 Object |
| **必填** | 否 |
| **默认值** | 当前日期-35天 至 当前日期-4天（约31天数据） |

**支持三种格式**：

##### 格式一：对象格式（推荐）

```json
{
  "historical_date_range": {
    "start": "2026-01-18",
    "days": 29
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `start` | String | 是 | 开始日期，格式：YYYY-MM-DD |
| `days` | Integer | 否 | 天数，默认31天 |

##### 格式二：字符串格式（兼容）

```json
{
  "historical_date_range": "2026-01-18 29"
}
```

格式说明：`"开始日期 天数"`，用空格分隔

##### 格式三：字符串格式（省略天数）

```json
{
  "historical_date_range": "2026-01-18"
}
```

默认使用31天数据

##### 不填写

使用默认逻辑：当前日期-35天 至 当前日期-4天

---

#### 2.2.4 `date_type_override` - 日期类型覆盖规则

| 属性 | 说明 |
|------|------|
| **类型** | Array[Object] 或 String |
| **必填** | 否 |
| **默认值** | 无 |
| **用途** | 指定某家公司在特定日期的日期类型（如：将某天的"工作日"改为"法定节假日"） |

**支持两种格式**：

##### 格式一：简化文本格式（推荐）

```json
{
  "date_type_override": "珠海华发新能源运营管理有限公司|2026-03-15|工作日|正常生产\n台山市人民医院|2026-03-03|法定节假日|不休息"
}
```

**格式规则**：
- 每行一条规则
- 字段用竖线 `|` 分隔
- 格式：`公司名|日期|类型|备注`
- 备注可省略
- **不允许空行**

##### 格式二：JSON数组格式（兼容）

```json
{
  "date_type_override": [
    {
      "company": "珠海华发新能源运营管理有限公司",
      "date": "2026-03-15",
      "modified_type": "工作日",
      "remark": "正常生产"
    },
    {
      "company": "台山市人民医院",
      "date": "2026-03-03",
      "modified_type": "法定节假日",
      "remark": "不休息"
    }
  ]
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `company` | String | 是 | 公司名称（需与支持列表完全一致） |
| `date` | String | 是 | 日期，格式：YYYY-MM-DD |
| `modified_type` | String | 是 | 覆盖后的日期类型 |
| `remark` | String | 否 | 备注说明 |

**`modified_type` 可选值**：

| 值 | 说明 |
|------|------|
| `工作日` | 周一至周五（非节假日） |
| `周六` | 周六 |
| `周日` | 周日 |
| `法定节假日` | 国家法定节假日 |
| `调休节假日` | 调休的节假日 |

## 五、输出文件说明

### 5.1 Excel文件结构

生成的Excel文件包含以下工作表：

| Sheet名称 | 说明 |
|-----------|------|
| **需求申报电量** | 汇总各公司的预测总用电量和日期统计 |
| **需求电量** | 汇总所有公司的每日逐时用电量预测 |
| **公司独立sheet** | 每个公司一个sheet，包含详细数据 |

### 5.2 需求申报电量 Sheet

| 列名 | 说明 |
|------|------|
| 公司名 | 公司名称 |
| 目标月份 | 预测的目标月份 |
| 预测总用电量 | 预测的总用电量（kWh） |
| 工作日天数 | 目标月份的工作日天数 |
| 周六天数 | 目标月份的周六天数 |
| 周日天数 | 目标月份的周日天数 |
| 法定节假日天数 | 目标月份的法定节假日天数 |
| 调休节假日天数 | 目标月份的调休节假日天数 |

### 5.3 需求电量 Sheet

| 列名 | 说明 |
|------|------|
| 公司名 | 公司名称 |
| 日期 | 预测日期 |
| 1时 ~ 24时 | 各时段预测用电量（kWh） |
| 日合计 | 当日预测总用电量 |

### 5.4 公司独立 Sheet

每个公司一个独立sheet，包含：

1. **历史数据区**：历史逐时负荷数据
2. **分析结果区**：
   - 各类型日期的平均用电量
   - 权重系数（保留14位小数）
   - 各类型日期的逐时占比
3. **预测结果区**：
   - 目标月份每日逐时预测用电量（保留2位小数）

## 六、工作流程

```
┌─────────────────┐
│   用户输入参数   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   EMS系统鉴权    │  ← 获取访问令牌
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  获取历史数据    │  ← 调用EMS接口获取31天逐时负荷数据
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   数据分析       │  ← 计算平均用电量、权重系数、逐时占比
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   用电量预测     │  ← 基于分析结果预测下月用电量
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   生成Excel      │  ← 生成月度需求申报表
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   返回文件URL    │
└─────────────────┘
```

## 七、错误码说明

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| `VALIDATION_ERROR` | 参数验证失败 | 检查参数格式是否符合要求 |
| `EMS_AUTH_FAILED` | EMS鉴权失败 | 检查EMS系统凭据配置 |
| `DATA_FETCH_FAILED` | 数据获取失败 | 检查公司名称是否正确，网络是否正常 |
| `NO_DATA` | 未获取到任何公司数据 | 确认指定公司在历史日期范围内有数据 |
| `EXCEL_GENERATION_FAILED` | Excel生成失败 | 检查日志定位具体错误 |

## 八、注意事项

### 8.1 参数处理规则

1. **target_month 默认值**：不填写时自动计算为当前月份+1
2. **historical_date_range 默认值**：不填写时使用当前日期-35天至-4天
3. **company_names 默认值**：不填写时使用所有14家公司
4. **日期类型数据**：2024-2026年的日期类型已内置，无需外部文件

### 8.2 数据精度

- **权重系数**：保留14位小数
- **预测用电量**：保留2位小数
- **历史数据**：使用EMS接口返回的原始精度

### 8.3 性能说明

- 单个公司数据获取耗时：约1-3秒
- 全部14家公司数据获取：约30-60秒
- 完整工作流执行时间：约1-2分钟

### 8.4 数据有效期

- 生成的Excel文件下载链接有效期：**24小时**
- 过期后需重新调用接口生成

## 九、技术细节

### 9.1 日期类型分类规则

系统内置了2024-2026年所有日期的类型分类：

| 类型 | 说明 | 权重系数 |
|------|------|----------|
| 工作日 | 周一至周五（非节假日） | 最高 |
| 周六 | 周六 | 中等 |
| 周日 | 周日 | 较低 |
| 法定节假日 | 国家法定节假日 | 最低 |
| 调休节假日 | 调休的节假日 | 较低 |

### 9.2 预测算法

1. **历史数据统计**：
   - 按日期类型分组计算平均用电量
   - 计算各类型日期的权重系数
   - 计算各类型日期的逐时用电占比

2. **预测计算**：
   - 统计目标月份各类型日期天数
   - 预测总用电量 = Σ(各类型平均用电量 × 天数 × 权重系数)
   - 预测逐时用电量 = 日用电量 × 逐时占比

### 9.3 数据来源

- **EMS系统**：https://ems.pmac.com.cn
- **历史负荷数据接口**：`/api/vpp-manage/v1/ps/load/predicting/unit/load/data`
