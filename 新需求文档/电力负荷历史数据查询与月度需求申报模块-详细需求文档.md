# 电力负荷历史数据查询与月度需求申报模块 - 详细需求文档

**文档版本**: v1.0
**创建日期**: 2026-03-19
**适用场景**: 现有Vue3 + Node.js Express网站新增功能模块

---

## 一、项目背景与目标

### 1.1 业务背景

当前系统需要新增"电力负荷历史数据查询与月度需求申报专家"模块，用于电力负荷管理场景。该模块通过调用外部EMS系统接口，获取各签约公司的历史逐时负荷数据，基于既定的算法模型进行分析预测，最终生成标准化的月度需求申报表Excel文件，供用户下载使用。

### 1.2 核心目标

- 实现与EMS系统的数据对接，自动获取历史负荷数据
- 基于历史数据进行统计分析，预测下月用电量
- 自动生成符合业务规范的Excel报表
- 提供友好的前端交互界面

#### F3: 获取EMS数据

**需求描述**: 根据选择的公司和月份，从EMS系统获取历史负荷数据

**数据处理流程**:

1. 确定历史数据的起止日期
   - 开始日期 = 当前日期 - 35天
   - 结束日期 = 当前日期 - 4天
   - 数据范围 = 32天（用于分析时取31天）

2. 对每个选择的公司，调用EMS接口获取数据

3. 数据预处理
   - 将小时数据按日期分组
   - 时间映射：接口返回的0-23小时 → 1时-24时
   - 计算每日总用电量（24小时之和）
   - 从辅助表匹配日期类型

**数据质量检查**:

- 确保获取31天完整数据
- 每天必须有24小时数据
- 数据缺失时记录异常，但继续处理

**后端接口定义**:

```
POST /api/ems/fetch-data
Request:
{
  "companyIds": ["1993139538440470529", "1971482090017280001"],
  "targetMonth": "2026-04"
}

Response:
{
  "success": true,
  "data": {
    "totalCompanies": 2,
    "successCount": 2,
    "failCount": 0,
    "companies": [
      {
        "companyId": "1993139538440470529",
        "companyName": "台山市人民医院",
        "dataRange": "2026-02-12 至 2026-03-15",
        "daysCount": 31,
        "status": "success"
      }
    ]
  }
}
```

#### F4: 数据分析与预测

**需求描述**: 基于历史数据计算各类日期的平均用电量和权重系数，预测下月用电量

**计算步骤**:

##### 步骤1: 数据分类汇总

对每个公司的31天历史数据，按日期类型（工作日、周六、周日、法定节假日、调休节假日）分组

##### 步骤2: 计算各类日期的平均用电量

```
工作日平均用电量 = 所有工作日日电量之和 ÷ 工作日天数
周六平均用电量 = 所有周六日电量之和 ÷ 周六天数
周日平均用电量 = 所有周日电量之和 ÷ 周日天数
法定节假日平均用电量 = 所有法定节假日日电量之和 ÷ 法定节假日天数
调休节假日平均用电量 = 所有调休节假日日电量之和 ÷ 调休节假日天数
```

##### 步骤3: 计算权重系数（以工作日为基准）

```
工作日权重系数 = 1.0
周六权重系数 = 周六平均用电量 ÷ 工作日平均用电量（保留14位小数）
周日权重系数 = 周日平均用电量 ÷ 工作日平均用电量（保留14位小数）
法定节假日权重系数 = 法定节假日平均用电量 ÷ 工作日平均用电量（保留14位小数）
调休节假日权重系数 = 调休节假日平均用电量 ÷ 工作日平均用电量（保留14位小数）
```

##### 步骤4: 计算各类日期的逐时电量占比

对每个日期类型，计算24小时的电量占比：

```
工作日逐时电量占比 = 工作日各小时平均电量 ÷ 工作日平均用电量
周六逐时电量占比 = 周六各小时平均电量 ÷ 周六平均用电量
...（其他类型同理）
```

##### 步骤5: 预测下月用电量

从辅助表获取下月各类型日期的天数，计算：

```
下月工作日预测用电量 = 工作日平均用电量 × 下月工作日天数
下月周六预测用电量 = 工作日平均用电量 × 周六权重系数 × 下月周六天数
下月周日预测用电量 = 工作日平均用电量 × 周日权重系数 × 下月周日天数
下月法定节假日预测用电量 = 工作日平均用电量 × 法定节假日权重系数 × 下月法定节假日天数
下月调休节假日预测用电量 = 工作日平均用电量 × 调休节假日权重系数 × 下月调休节假日天数

下月预测总用电量 = 以上各项之和（保留2位小数）
```

##### 步骤6: 生成下月每日预测数据

对下月的每一天：

1. 根据日期类型，选择对应的平均用电量
2. 计算该日24小时的逐时电量：
   ```
   每小时电量 = 该类型平均用电量 × 该类型逐时电量占比
   ```

**计算精度要求**:

- 权重系数：保留14位小数
- 最终预测用电量：保留2位小数
- 逐时电量：保留5位小数

## 四、非功能需求

### 4.1 性能要求

- 单次报表生成时间 ≤ 30秒（处理10个公司以内）
- 支持最多同时处理20个公司
- EMS接口调用超时时间：30秒
- 接口失败自动重试：最多3次

### 4.2 可用性要求

- 前端界面响应时间 < 500ms
- 操作流程清晰，提供进度提示
- 异常情况有明确的错误提示

### 4.3 数据准确性要求

- 计算精度严格遵守业务规则
- 权重系数保留14位小数
- 预测电量保留2位小数
- 逐时电量保留5位小数

### 4.4 兼容性要求

- 支持主流浏览器（Chrome、Firefox、Edge、Safari最新版本）
- Excel文件兼容Excel 2016及以上版本
- 支持移动端浏览器访问（响应式设计）

## 五、数据模型设计

### 5.1 核心数据结构

#### Company（公司信息）

```typescript
interface Company {
  companyId: string; // EMS系统中的公司ID
  companyCode: string; // 企业代码（如CYH006093）
  companyName: string; // 公司名称
  category: string; // 类别（医院/企业）
}
```

#### DateTypeInfo（日期类型信息）

```typescript
interface DateTypeInfo {
  date: string; // 日期 YYYY-MM-DD
  weekday: string; // 星期（中文）
  type: DateType; // 日期类型
  holidayName?: string; // 节假日名称（如适用）
}

type DateType = "工作日" | "周六" | "周日" | "法定节假日" | "调休节假日";
```

#### LoadData（负荷数据）

```typescript
interface LoadData {
  companyId: string; // 公司ID
  companyName: string; // 公司名称
  dateRange: {
    start: string; // 开始日期
    end: string; // 结束日期
  };
  dailyData: DailyLoadData[]; // 每日数据数组（31天）
}

interface DailyLoadData {
  date: string; // 日期 YYYY-MM-DD
  weekday: string; // 星期
  type: DateType; // 日期类型
  dailyLoad: number; // 日电量
  hourlyLoad: number[]; // 24小时电量数组，索引0对应1时，索引23对应24时
}
```

#### AnalysisResult（分析结果）

```typescript
interface AnalysisResult {
  companyId: string;
  companyName: string;
  baseMonth: {
    totalLoad: number; // 本月实际总用电量
    typeStats: TypeStats[];
  };
  typeStats: TypeStats[]; // 各类日期统计
  prediction: Prediction; // 下月预测
}

interface TypeStats {
  type: DateType;
  days: number; // 该类型天数
  weight: number; // 权重系数（工作日为1）
  avgDailyLoad: number; // 平均日电量
  hourlyRatio: number[]; // 逐时电量占比（24个值）
}

interface Prediction {
  month: string; // 预测月份 YYYY-MM
  totalPrediction: number; // 预测总用电量
  typePredictions: TypePrediction[];
  dailyPrediction: DailyPrediction[]; // 每日预测
}

interface TypePrediction {
  type: DateType;
  days: number; // 该类型天数
  prediction: number; // 预测用电量
}

interface DailyPrediction {
  date: string;
  weekday: string;
  type: DateType;
  dailyLoad: number;
  hourlyLoad: number[];
}
```

### 5.2 数据流转图

```
EMS接口数据
    ↓

    ↓
日期类型匹配（从辅助表）
    ↓

    ↓
权重系数计算
    ↓
逐时占比计算
    ↓

    ↓
```

#### 6.2.2 dataAnalysisService.js - 数据分析与计算

**职责**: 负责所有数据计算逻辑

**核心函数设计**:

1. `preprocessData(rawData, auxiliaryData)`
   - 输入：EMS原始数据、辅助表数据
   - 处理：
     - 将小时数据按日期分组
     - 时间映射（0-23 → 1-24时）
     - 计算日电量
     - 匹配日期类型
   - 输出：标准化的日负荷数据数组

2. `calculateTypeStats(dailyData)`
   - 输入：31天的日负荷数据
   - 处理：
     - 按日期类型分组
     - 计算各类日期的平均用电量
     - 计算权重系数（以工作日为基准）
     - 计算逐时电量占比
   - 输出：TypeStats数组

3. `predictMonth(typeStats, monthStats)`
   - 输入：历史分析结果、下月日期统计
   - 处理：
     - 计算各类日期的预测用电量
     - 汇总得到下月预测总用电量
   - 输出：Prediction对象

4. `generateDailyPrediction(typeStats, monthDays)`
   - 输入：历史分析结果、下月日期列表
   - 处理：
     - 对下月每一天，根据类型计算日电量和逐时电量
   - 输出：DailyPrediction数组

5. `analyzeCompany(companyId, targetMonth, loadData, auxiliaryData)`
   - 主分析函数，整合上述所有步骤
   - 输入：公司ID、目标月份、EMS数据、辅助表数据
   - 输出：完整的AnalysisResult

**计算精度控制**:

```javascript
// 权重系数保留14位小数

// 预测电量保留2位小数
```

```javascript
// generateReport控制器
async generateReport(req, res) {
  try {
    const { companyIds, targetMonth } = req.body;

    // 1. 参数校验
    if (!companyIds || companyIds.length === 0) {
      return res.status(400).json({
        success: false,
        message: '请选择至少一家公司'
      });
    }

    // 2. 获取月份统计
    const monthStats = await dateHelper.getMonthStats(targetMonth);

    // 3. 并发获取所有公司的EMS数据
    const companiesData = await Promise.all(
      companyIds.map(companyId => emsService.getCompanyData(companyId))
    );

    // 4. 对每个公司进行数据分析
    const analysisResults = await Promise.all(
      companiesData.map(data =>
        dataAnalysisService.analyzeCompany(
          data.companyId,
          targetMonth,
          data.loadData,
          data.auxiliaryData
        )
      )
    );

    // 5. 生成Excel文件
    const fileName = `月度需求申报表_${dateHelper.getCurrentDate()}.xlsx`;
    const filePath = excelService.generateReport(
      analysisResults,
      monthStats,
      targetMonth,
      fileName
    );

    // 6. 返回结果
    res.json({
      success: true,
      data: {
        fileName,
        downloadUrl: `/api/ems/download/${fileName}`,
        summary: {
          totalCompanies: analysisResults.length,
          totalPrediction: analysisResults.reduce((sum, r) => sum + r.prediction.totalPrediction, 0)
        }
      }
    });

  } catch (error) {
    console.error('生成报表失败:', error);
    res.status(500).json({
      success: false,
      message: '生成报表失败: ' + error.message
    });
  }
}
```

```javascript
const cron = require("node-cron");
const fs = require("fs");
const path = require("path");

// 每小时清理一次临时文件
cron.schedule("0 * * * *", () => {
  const tempDir = "./uploads/temp";
  const files = fs.readdirSync(tempDir);

  const now = Date.now();
  const keepTime = 3600000; // 1小时

  files.forEach((file) => {

    }
  });
});
```

## 十一、常见问题FAQ

### Q1: 如果EMS接口返回的数据不足31天怎么办？

**A**: 系统会使用实际返回的天数进行分析，但会在Excel中标注数据异常。建议检查EMS数据完整性或联系EMS系统管理员。

### Q2: 如何处理权重系数计算时除数为0的情况？

**A**: 如果工作日平均用电量为0（理论上不应出现），则无法计算权重系数。此时应使用默认权重系数1.0，并在日志中记录异常。

### Q3: 生成的Excel文件可以保存多久？

**A**: 临时文件默认保留1小时，之后会被定时任务自动清理。如需长期保存，用户应立即下载到本地。

### Q4: 支持批量生成多个月的报表吗？

**A**: 当前版本不支持。如需生成多月报表，需要多次操作，每次选择不同的月份。

### Q5: 如何验证预测结果的准确性？

**A**: 可以将预测结果与实际用电量进行对比，计算误差率。建议定期校准预测算法，优化权重系数计算方式。
