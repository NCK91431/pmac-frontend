## 接口列表

### 1. 生成申报表

**路径：** `POST /declaration/generate`

生成指定日期的日前申报表 Excel 文件并返回下载。

**请求头：**

```
Content-Type: application/json
```

**请求参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `declaration_date` | string | **是** | — | 申报日期，格式 `YYYY-MM-DD`，如 `"2026-03-22"` |
| `load_mode` | string | 否 | `"算法预测"` | 提供算法预测、人工经验 两个选项 |
| `probability_window` | object | 否 | `{"type": "all", "days": 7}` | 概率计算窗口配置，详见下方说明 |
| ratio | list | 否 | [None] * 24 | 每小时的调整申报比例 |

**probability_window 参数子字段：**

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `type` | string | 日期筛选类型，支持以下几种：<br/>• `"all"`：不筛选，按自然日取<br/>• `"workday"`：仅工作日（周一~周五，排除节假日）<br/>• `"周一"` ~ `"周日"`：指定星期几（如 `"周六"`）<br/>• `"holiday"` : 调休节假日或法定节假日 |
| `days` | int | 向前取最近 N 天（按自然日或筛选后连续天数） |
| `period` | int | 向前取最近 N 个“同类周期” |

`days` 和 `period` **二选一**，不可同时使用

**请求示例：**

```json
POST /declaration/generate
{
    "declaration_date": "2026-03-22",
    "prediction_mode": "算法预测",
    "probability_window": {
        "type": "周日",
        "period": 7
    },
    "ratio": [None,None,...,None]
}

{
    "declaration_date": "2026-03-22",
    "prediction_mode": "算法预测",
    "probability_window": {
        "type": "workday",
        "period": 11
    },
    "ratio": [None,None,...,None]
}

{
    "declaration_date": "2026-03-22",
    "prediction_mode": "算法预测",
    "probability_window": {
        "type": "all",
        "period": 7
    },
    "ratio": [None,None,...,None]
}

{
    "declaration_date": "2026-03-22",
    "prediction_mode": "算法预测",
    "probability_window": {
        "type": "法定节假日",
        "period": 7
    },
    "ratio": [None,None,...,None]
}

{
    "declaration_date": "2026-03-22",
    "prediction_mode": "算法预测",
    "probability_window": {
        "type": "调休节假日",
        "period": 7
    },
    "ratio": [None,None,...,None]
}
```

**成功响应：**

- **HTTP 200**
- **Content-Type：** `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- **Content-Disposition：** `attachment; filename=日前申报表_2026-03-22.xlsx`
- 返回 Excel 文件二进制流，直接触发下载

**错误响应：**

```json
{
    "success": false,
    "error": "缺少必填参数: declaration_date"
}
```

| HTTP状态码 | 说明 |
|-----------|------|
| 400 | 参数缺失、数据文件未找到 |
| 500 | 服务器内部异常 |
