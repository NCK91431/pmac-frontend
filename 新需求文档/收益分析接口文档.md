# 收益分析接口文档

## 接口一：下载 Excel 报表

### `/revenue/generate`

**请求方式：** POST

**功能：** 生成并下载日前申报表和收益分析表 Excel 文件

---

#### 请求参数 (Request Body)

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `declaration_date` | string | 是 | - | 申报日期，格式：`YYYY-MM-DD` |
| `load_mode` | string | 否 | `"算法预测"` | 负荷预测模式，支持：`"算法预测"`, `"均值预测"` |
| `mode_declaration` | string | 否 | `"算法预测"` | 概率计算模式，支持：`"算法预测"`, `"手动"` |
| `probability_window` | object | 否 | `{"type": "all", "days": 7}` | 概率计算窗口配置 |
| `ratio` | array | 否 | `[null] * 24` | 申报比例，24小时数组 |

#### 请求示例

```json
{
    "declaration_date": "2026-04-15",
    "load_mode": "算法预测",
    "mode_declaration": "算法预测",
    "probability_window": {"type": "all", "days": 7},
    "ratio": [null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null]
}
```

#### 响应

**Content-Type:** `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

**Content-Disposition:** `attachment; filename=日前申报表_{日期}.xlsx`

返回日前申报表 Excel 文件下载。

---

## 接口二：获取 JSON 数据

### `/revenue/data`

**请求方式：** POST

**功能：** 获取日前申报数据（JSON 格式），同时生成 Excel 报表文件

---

#### 请求参数 (Request Body)

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `declaration_date` | string | 是 | - | 申报日期，格式：`YYYY-MM-DD` |
| `load_mode` | string | 否 | `"算法预测"` | 负荷预测模式，支持：`"算法预测"`, `"均值预测"` |
| `mode_declaration` | string | 否 | `"算法预测"` | 概率计算模式，支持：`"算法预测"`, `"手动"` |
| `probability_window` | object | 否 | `{"type": "all", "days": 7}` | 概率计算窗口配置 |
| `ratio` | array | 否 | `[null] * 24` | 申报比例，24小时数组 |

#### 请求示例

```json
{
    "declaration_date": "2026-04-15",
    "load_mode": "算法预测",
    "mode_declaration": "算法预测",
    "probability_window": {"type": "all", "days": 7},
    "ratio": [null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null, null]
}
```

#### 成功响应

```json
{
    "success": true,
    "data": [
        {
            "time": "00:00",
            "declaration_mwh": 10.5,
            "spread": -1,
            "yearly_hourly": 5.0,
            "yearly_price": 372.0,
            "monthly_hourly": 3.0,
            "monthly_price": 381.05,
            "duori_hourly": 2.5,
            "duori_price": 0.0,
            "week_hourly": 0.0,
            "week_price": 0.0,
            "jiaoyi3_hourly": 0.0,
            "jiaoyi3_price": 0.0,
            "actual_hourly": 10.0,
            "dayahead_set_price": 350.0,
            "realtime_set_price": 345.0,
            "profit": 1500.0
        },
        ...
    ]
}
```

#### data 数组元素说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `time` | string | 时间点，格式：`HH:MM` |
| `declaration_mwh` | float | 日前申报电量（兆瓦时） |
| `spread` | int | 价差方向，`-1` = 实时>日前，`1` = 日前>=实时 |
| `yearly_hourly` | float | 年度合约电量（兆瓦时） |
| `yearly_price` | float | 年度电能量价格（元/兆瓦时） |
| `monthly_hourly` | float | 月度合约电量（兆瓦时） |
| `monthly_price` | float | 月度电能量价格（元/兆瓦时） |
| `duori_hourly` | float | 多日合约电量（兆瓦时） |
| `duori_price` | float | 多日电能量价格（元/兆瓦时） |
| `week_hourly` | float | 周合约电量（兆瓦时） |
| `week_price` | float | 周电能量价格（元/兆瓦时） |
| `jiaoyi3_hourly` | float | 备用合约电量（兆瓦时） |
| `jiaoyi3_price` | float | 备用合约价格（元/兆瓦时） |
| `actual_hourly` | float | 实际用电量（兆瓦时） |
| `dayahead_set_price` | float | 日前出清价格（元/兆瓦时） |
| `realtime_set_price` | float | 实时出清价格（元/兆瓦时） |
| `profit` | float | 收益金额（元） |

#### 失败响应

```json
{
    "success": false,
    "error": "缺少必填参数: declaration_date"
}
```
