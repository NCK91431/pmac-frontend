# 日期类型辅助表数据库表设计方案

## 1. 表结构设计

### 表名：`auxiliary_date_info`

| 字段名            | 数据类型          | 约束                                                      | 描述                    |
| :------------- | :------------ | :------------------------------------------------------ | :-------------------- |
| `id`           | `INT`         | `PRIMARY KEY AUTO_INCREMENT`                            | 自增主键                  |
| `date`         | `DATE`        | `UNIQUE NOT NULL`                                       | 日期                    |
| `date_type`    | `VARCHAR(20)` | `NOT NULL`                                              | 日期类型（如：法定节假日、工作日、周末等） |
| `holiday_name` | `VARCHAR(50)` | `DEFAULT NULL`                                          | 节假日名称（如：元旦、春节等）       |
| `created_at`   | `TIMESTAMP`   | `DEFAULT CURRENT_TIMESTAMP`                             | 创建时间                  |
| `updated_at`   | `TIMESTAMP`   | `DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新时间                  |

## 2. 数据类型映射

| Excel列 | 数据库字段         | 数据类型        | 转换说明                |
| :----- | :------------ | :---------- | :------------------ |
| 日期     | date          | DATE        | Excel日期序列值转换为标准日期格式 |
| 日期类型   | date\_type    | VARCHAR(20) | 直接存储文本值             |
| 节假日名称  | holiday\_name | VARCHAR(50) | 直接存储文本值，空值存储为NULL   |

## 3. 存储方案

### 3.1 数据导入步骤

1. **数据预处理**：
   - 将Excel中的日期序列值转换为标准日期格式（YYYY-MM-DD）
   - 处理空值，确保数据完整性
2. **数据库连接**：
   - 使用项目现有的数据库连接配置
   - 建议使用MySQL数据库，与项目其他模块保持一致
3. **数据导入**：
   - 创建表结构
   - 批量导入数据
   - 建立日期字段的唯一索引，确保数据唯一性

### 3.2 索引设计

- **主键索引**：`id`字段（自增主键）
- **唯一索引**：`date`字段（确保日期不重复）
- **普通索引**：`date_type`字段（加速按日期类型查询）

### 3.3 数据验证

- 检查日期格式是否正确
- 验证日期类型值的合法性
- 确保没有重复日期

## 4. 技术实现建议

### 4.1 后端实现

- 使用Node.js + Express框架
- 利用`xlsx`库读取Excel文件
- 使用`mysql2`或`sequelize`进行数据库操作
- 实现数据导入API接口

### 4.2 前端实现

- 复用现有的文件上传组件
- 提供导入进度和结果反馈
- 支持手动编辑和更新数据

## 5. 数据使用场景

- 辅助交易工具中的日期类型判断
- 节假日交易策略调整
- 历史数据查询和分析
- 报表生成中的日期分类

## 6. 性能优化

- 批量导入数据，减少数据库操作次数
- 合理设计索引，提高查询效率
- 定期清理冗余数据，保持表结构简洁

## 7. 维护建议
